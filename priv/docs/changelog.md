# Changelog

## 0.1.0

Initial public release of Glodin for stock Gleam on Erlang.

- Typed Odin NIF annotations and generated Gleam declarations, Erlang loaders,
  and C/Odin adapters.
- Stock-Gleam wrapper for scaffolding, native dependency builds, development
  commands, source packages and optimized production shipments.
- Incremental builds, native resources, ownership helpers, lifecycle callbacks,
  background jobs, codecs, scheduler selection and versioned native upgrades.
- Source-only publication with packaged native inputs, dual license texts,
  ownership documentation, examples and a real-BEAM conformance suite.

Supported toolchain: Gleam 1.19.1+, Odin dev-2026-07a, OTP 27–29,
Linux/macOS on arm64/x64. Full Rustler certification, Windows, certified
cross-compilation and prebuilt-binary package distribution are deferred.
